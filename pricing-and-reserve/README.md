# Pricing Uncollateralized Microcredit on a Public Blockchain

**Pricing Uncollateralized Microcredit on a Public Blockchain: Short Loans, Re-lending and a Locked
First-Loss Reserve.** Working paper, prepared for The Journal of Credit Risk.

- [paper.pdf](paper.pdf): the compiled paper.
- [JOURNALS.md](JOURNALS.md): the paper's discipline, three target journals, and what is out of scope.
- `paper.tex`, `references.bib`, `figures/`: the sources. The figures are pgfplots.
- `data/`: every table and curve, generated by the scripts.
- `scripts/`: `locked_reserve.py` (the paper's own simulation of the reserve) and
  `extract_credit_risk.py` (tables and curves from the contract repository's calibration).

## Results

| In the paper | Statement |
| --- | --- |
| Proposition 1 | Per-loan and annual default probabilities under a constant hazard; defaults per exposure-year with replacement lie between the PD and the hazard |
| Proposition 2 | Re-lending maps Vasicek quantiles through an increasing function, so the re-lent quantile is exact |
| Proposition 3 | The pool-level break-even premium, with idle cash and a fee |
| Theorem 1 | Lenders' cumulative return = gross interest net of fees − losses − the reserve's final balance, under any release policy |
| Theorem 2 | With a reserve that is never released, lenders' long-run return is u[a(1−f) − max(EL, a·r)] |
| Corollary 1 | At the protocol's production settings, lenders' long-run expected return is 3.67%, below the 4.33% funding rate |

## Build

```bash
make            # latexmk -pdf paper.tex
```

## Reproduce the data

The contract repository is https://github.com/scottonchain/microcredit-contract at commit `b725a85`.

```bash
python3 analysis/credit_risk/run.py                          # in the contract repository, about 25 s
python3 scripts/locked_reserve.py <path to microcredit-contract>       # about 1 minute
python3 scripts/extract_credit_risk.py <path to microcredit-contract>
```

Both scripts are deterministic: the simulation seeds every case from a fixed seed sequence.
